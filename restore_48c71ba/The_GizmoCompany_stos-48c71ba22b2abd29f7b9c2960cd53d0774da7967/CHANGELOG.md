# Changelog

All notable changes to ZENO Browser will be documented in this file.

## [0.1.0] - 2026-03-14

### Added
- Initial release of ZENO Browser
- Multi-tab browser interface
- AI Gateway with DeepSeek, OpenRouter, EdenAI support
- Plugin system with marketplace
- Cloudflare WebTunnel integration
- Security sandbox per tab
- Network monitoring
- Auto-update system
- Multi-platform installers (Windows, macOS, Linux)

### Features
- ✅ Own browser engine (Electron-based)
- ✅ AI-powered features
- ✅ Plugin ecosystem
- ✅ Secure tunneling
- ✅ Advanced monitoring

### Security
- Renderer process isolation
- Network request validation
- Permission-based plugin system
- Encrypted communication
