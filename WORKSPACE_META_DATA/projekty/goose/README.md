# goose workspace

Katalog roboczy agenta **goose** w ZENO Browser Agent Workspace.

## Jak używać

Agent goose uruchamia się z CWD = ten katalog.
Zapisuj pliki tutaj — są izolowane od głównego projektu.

## Wdrożenie

Gotowe pliki → skopiuj do `src/` lub `WORKSPACE_META_DATA/addons/` i uruchom przez Goose/VSCode.
