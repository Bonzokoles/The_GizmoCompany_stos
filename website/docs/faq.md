# FAQ - Frequently Asked Questions

## General

### What is ZENO Browser?

ZENO Browser is an AI-powered web browser that combines modern browsing with artificial intelligence features.

### Is ZENO Browser free?

Yes! ZENO Browser is completely free and open-source.

### What's different about ZENO Browser?

- Built-in AI Assistant (DeepSeek integration)
- Plugin ecosystem
- Cloudflare Tunnel support
- Focus on privacy and security

## Installation & Setup

### System Requirements?

- Windows 10+ (64-bit), macOS 10.13+, or Ubuntu 18.04+
- 4GB RAM minimum
- 500MB disk space

### Can I use ZENO on USB drive?

Yes! Download the portable version on Windows or use AppImage on Linux.

## Features

### How do I use the AI Assistant?

1. Click the 🤖 icon in toolbar
2. Type your question
3. Get responses from DeepSeek

### Can I use my own AI provider?

Yes! Configure in Settings → AI:
- DeepSeek (default)
- OpenRouter
- EdenAI
- Custom endpoints

### What is Cloudflare Tunnel?

Secure tunnel to access your local applications publicly with Cloudflare's security.

## Plugins

### How do I install plugins?

1. Click 🔌 Plugin Manager
2. Browse or search marketplace
3. Click "Install"

### Can I create my own plugin?

Yes! See [Plugin Development Guide](./plugin-development/overview.md)

### Is there a plugin marketplace?

Yes! Official plugins at https://marketplace.zeno-browser.io

## Privacy & Security

### Does ZENO collect my data?

No. We don't collect browsing data, search history, or personal information.

### How secure is it?

- Encrypted communication
- Sandboxed plugins
- No tracking
- Open-source code

### Can I use Cloudflare Tunnel safely?

Yes. Tunnel encrypts all traffic through Cloudflare's edge network.

## Troubleshooting

### Application crashes on startup?

Try:
1. Restart computer
2. Reinstall application
3. Check system logs

### Slow performance?

- Close unused tabs
- Disable unnecessary plugins
- Check disk space
- Update to latest version

### Can't download plugins?

- Check internet connection
- Try different plugin
- Check firewall settings
