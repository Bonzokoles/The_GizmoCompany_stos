# Getting Started with ZENO Browser

Welcome to ZENO Browser - the AI-powered web browser with DeepSeek integration!

## What is ZENO Browser?

ZENO Browser is a modern, privacy-focused web browser that combines:
- 🤖 **AI Integration** - DeepSeek, OpenRouter, EdenAI support
- 🔌 **Plugin System** - Extend functionality with plugins
- 🌐 **Cloudflare Tunnel** - Secure tunneling for your applications
- 🔒 **Security** - Built-in sandbox and monitoring

## Quick Start

### 1. Installation

Choose your platform:
- [Windows](./installation/windows.md)
- [macOS](./installation/macos.md)
- [Linux](./installation/linux.md)

### 2. First Run

When you first launch ZENO Browser:
1. Choose your default search engine
2. Optionally configure AI features
3. Install recommended plugins

### 3. Using AI Features

1. Click the **🤖 AI Assistant** button
2. Enter your prompt
3. Choose AI provider (defaults to DeepSeek)
4. Get instant responses
