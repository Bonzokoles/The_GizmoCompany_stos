# Installing ZENO Browser on Windows

## System Requirements

- Windows 10 or later (64-bit)
- 4GB RAM minimum (8GB recommended)
- 500MB free disk space
- .NET Framework 4.5+ (usually pre-installed)

## Installation Methods

### Method 1: Installer (Recommended)

1. Download `ZENO Browser Setup x.x.x.exe` from [GitHub Releases](https://github.com/Bonzokoles/zen-bro-wser.org/releases)

2. Run the installer:
   - Double-click the `.exe` file
   - Follow the installation wizard
   - Choose installation directory
   - Select optional components

3. Launch ZENO Browser:
   - From Start Menu
   - Or find the icon on your Desktop

### Method 2: Portable Version

1. Download `ZENO Browser x.x.x.exe` (portable)

2. Run directly without installation:
   - No admin rights required
   - Can run from USB drive
   - Settings stored locally

### Method 3: Windows Package Manager

```powershell
winget install ZENO.Browser
```

## Uninstall

### Using Control Panel

1. Open Settings → Apps → Apps & features
2. Find "ZENO Browser"
3. Click Uninstall
4. Confirm removal

### Using Installer

1. Run the installer again
2. Choose "Uninstall"
3. Follow the prompts

## Troubleshooting

### "Windows protected your PC"

This is a security warning for unsigned installers. To proceed:

1. Click "More info"
2. Click "Run anyway"
3. Continue with installation

### Application won't start

1. Check Windows Defender isn't blocking it
2. Run as administrator
3. Reinstall the application

### Slow performance

- Close unnecessary applications
- Check disk space (need at least 1GB free)
- Update Windows
- Check for antivirus interference

## Configuration

### First Run Setup

1. **Search Engine** - Choose default search engine
2. **AI Configuration** - Set up API keys
3. **Privacy** - Configure privacy settings

### Keyboard Shortcuts

- `Ctrl+T` - New tab
- `Ctrl+W` - Close tab
- `Ctrl+Shift+Delete` - Clear browsing data
- `F12` - Developer tools
